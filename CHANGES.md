# Changes

## v0.1.1

First tagged release (the in-development v0.1.0 was never tagged).

Conference Submissions: a Moodle activity for running a call for abstracts.
Part of the Conference Tools suite.

- Presenters submit a title, abstract and speakers, with optional word and
  character limits enforced as they type and again on save.
- Organisers configure custom fields, tracks, submission types and optional
  preferred conference days.
- Submitters can withdraw their own submission; editing teachers with *Edit any
  submission* can edit or unwithdraw any submission; managers can delete.
- Editable notification templates, switchable per activity.
- Backup/restore and course reset.
- Declare Moodle 5.3 support (supported on Moodle 5.2–5.3).
- Speaker-row border follows Boost's dark colour mode (uses the theme border colour).
- Installable with Composer (`adamjenkins/moodle-mod_confsubmissions`).
- Releases are published to the camp registry.

See `changelog.md` for the full development history of this version.
